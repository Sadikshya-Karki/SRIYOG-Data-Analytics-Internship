# Nepal Home Services Market Analysis

**Prepared for:** Sriyog Consulting | **Date:** June 2026

## About
Competitive landscape analysis of 25 home service companies in Kathmandu,
covering 267 services across 7 categories, with a gap analysis against Tackles Pro.

## Files
| File | Description |
|------|-------------|
| `Nepal_Home_Services_Dataset.xlsx` | Raw dataset |
| `Nepal_Home_Services.ipynb` | Analysis and visualizations |
| `Nepal_Home_Services.html` | HTML export |
| `Nepal_Home_Services_Market_Analysis.pdf` | Final report |

## Key Findings
- Home Repair (28.8%) and Technical Services (28.5%) dominate the market
- Pressure Washing and Airbnb Maintenance are completely absent
- EV Charger Installation has only 1 provider
- 80% of companies have no transparent pricing
- Only 1 company offers full online cart and payment
