# Training Providers

**Prepared for:** Sriyog Consulting | **Date:** June 2026

## About
Mapping of 55 training institutions across 40 service categories
in the Kathmandu district, covering provider types and fee structures.

## Files
| File | Description |
|------|-------------|
| `Training_Providers.xlsx` | Raw dataset |
| `Training_Providers.ipynb` | Analysis and visualizations |
| `Training_Providers.html` | HTML export |
| `Training_Providers.pdf` | Final report |

## Key Findings
- 215 listings across 55 unique providers
- Electrical Repair has the most training providers (14)
- Packing and Moving has no training provider identified
- 85.5% of training is paid; only 14.5% is free or subsidized
- Apex Skills Academy covers the most categories (12)

## Tools Used
