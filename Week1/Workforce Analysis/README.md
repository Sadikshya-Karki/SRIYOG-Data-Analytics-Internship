# Workforce Analysis

**Prepared for:** Sriyog Consulting | **Date:** June 2026

## About
Supply and demand assessment across 40 service categories,
identifying workforce gaps and competition levels.

## Files
| File | Description |
|------|-------------|
| `Workforce_Analysis.xlsx` | Raw dataset |
| `Workforce_Analysis.ipynb` | Analysis and visualizations |
| `Workforce_Analysis.html` | HTML export |
| `Workforce_Analysis.pdf` | Final report |

## Key Findings
- Only 5 categories (12.5%) are well-served
- 40% of categories have limited workforce supply
- EV Charger Installation and Home Automation are critically underserved
- No high-demand category has low competition

## Tools Used
- Python (pandas, matplotlib, seaborn)
- Jupyter Notebook
- Microsoft Excel
