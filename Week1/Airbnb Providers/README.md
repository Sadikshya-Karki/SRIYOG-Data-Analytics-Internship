# Airbnb Providers

**Prepared for:** Sriyog Consulting | **Date:** June 2026

## About
Analysis of 90 Airbnb providers in Kathmandu examining host type,
ratings, reviews, and hosting tenure.

## Files
| File | Description |
|------|-------------|
| `Airbnb_Providers.xlsx` | Raw dataset |
| `Airbnb_Providers.ipynb` | Analysis and visualizations |
| `Airbnb_Providers.html` | HTML export |
| `Airbnb_Providers.pdf` | Final report |

## Key Findings
- 54% of providers hold Superhost status
- Average rating across all providers: 4.891 / 5.0
- Superhosts average 176.1 reviews vs 28.9 for regular Hosts
- Hosting tenure strongly correlates with Superhost status
