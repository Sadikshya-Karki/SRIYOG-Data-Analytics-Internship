# Comparative Analysis

**Prepared for:** Sriyog Consulting | **Date:** June 2026

## About
Comparison of 40 service categories across 314 provider listings,
examining competition intensity and provider type distribution.

## Files
| File | Description |
|------|-------------|
| `Comparative_Analysis.xlsx` | Raw dataset |
| `Comparative_Analysis.ipynb` | Analysis and visualizations |
| `Comparative_Analysis.html` | HTML export |
| `Comparative_Analysis.pdf` | Final report |

## Key Findings
- Plumbing (20) and Electrical Repair (19) are the most competitive categories
- AirBnB Maintenance, Drywall Repair, and Home Automation have only 2 providers each
- Organized companies lead at 48.1%; app platforms follow at 37.3%
- Sajilo Sewa appears across the most categories (19 of 40)
